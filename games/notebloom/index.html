  1. 좌우로 드래그

    손가락을 움직여 레인을 바꿔요. PC에서는 방향키나 A / D도 사용할 수 있어요.

  2. 음표로 체력 회복

    음표가 발밑의 판정선에 도착할 때 같은 레인에 있으면 구출! 음표마다 체력을 회복해요. 한 게임에서 50개를 모을 때마다 공격력이 5%씩 올라요.

  3. 무기를 주워 화력 강화

    모든 길에서 전방으로 자동 사격해요. 기본 30초마다 무기가 등장하며 탄약을 다 쓰면 무한 탄약 권총으로 돌아가요. 사용 중에는 다른 무기로 바뀌지 않아요.

  4. 곡이 끝나기 전에 보스 격파

    내 체력이 0이 되거나, 곡이 끝나도 보스가 남으면 실패해요. 보스를 잡은 뒤에도 음표를 놓치지 마세요.
