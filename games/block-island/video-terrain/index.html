5·6단계에서는 위에서 자른 수평 단면과 옆에서 자른 수직 단면을 함께 보세요. 지도를 누르면 그 위치의 세로 단면과 수치를 확인합니다.




지도를 눌러 같은 좌표의 F, 3단계 높이와 4단계 높이를 비교하세요.

옆에서 자른 수직 단면
가로 x = −128…126 / 세로 y = 40…159. 노란 선은 선택한 수평 단면 높이입니다.


돌물공기깎아낸 공기 · 강조색밀도 색상: 파랑 D≤0 / 따뜻한 색 D>0


표면 조망 · 내부는 위의 단면으로 확인
가로 8칸·높이 2칸 간격의 가벼운 표본입니다. 내부 공동과 얇은 구조는 생략될 수 있습니다. 자동 높이 확대 없이 같은 배율을 사용합니다.


확인된 내용과 구현 가정
영상 캡처·자막에서 확인
  • octaves = 4, surfaceY = 100 + noise.sample2d(x,z)*20, 높이 아래 STONE / 나머지 AIR.
  • 절벽 점: (−1,50), (0.3,100), (0.4,150), (1,150). 접선·보간 방식은 없음.
  • 3D 위치별 밀도에 고도 편향: 위에서는 감소, 아래에서는 증가.
  • 동굴 예시 조건: N3 < 0, abs(N3) < r.
  • 해수면 102의 물 판정은 앞서 제공된 자막의 설명을 유지.
이 실험에서 정한 선택
  • 시드 기반 Perlin, 2D 배율 0.01. 4옥타브는 정규화하지 않은 합 F. 단일 노이즈는 2단계 비교용.
  • 절벽은 선형 보간. F가 −1보다 작으면 50, 0.4 이상이면 150으로 고정. F는 −1.875…1.875 범위 가능.
  • D = (H4 − y)/24 + 세기×N3, 3D 배율 0.035, D>0에서 돌. 이 전체 식은 캡처에 없음.
  • 동굴은 밀도에서 이미 돌인 곳만 깎고 내부는 마른 공기로 둠. 물리적 침수·연결성 계산 없음.
  • 한 개 3D 노이즈의 0 근처 띠는 면처럼 이어질 수 있음. 스파게티 터널을 보장하지 않음.
공유 F를 써도 절벽 곡선은 평균 높이·해안선을 크게 바꿉니다. 영상의 실제 전체 코드나 마인크래프트 생성기를 복제한 것은 아닙니다. 고도 40…159와 제한된 영역의 표본이며 구조의 연결성이나 무한 월드 성능을 검증하지 않습니다.


대륙성·침식·봉우리/계곡·바이옴은 어디에 들어가나요?
Continentalness(대륙성), Erosion(침식), Peaks & Valleys(봉우리·계곡)는 높이와 관련된 별도 필드로 설명됩니다. 캡처에 정확한 결합식이 없어 이 실험의 높이식에 임의로 섞지 않았습니다.
바이옴 표는 이 세 특성과 온도·습도에 따른 분류를 설명합니다. 다섯 개의 특성 값으로 조건을 고르는 개념이며, 실제 공간이 5차원이라는 뜻은 아닙니다. 이 실험에는 바이옴 분류기를 구현하지 않았습니다.
