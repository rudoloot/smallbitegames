BLOCK ISLAND / TERRAIN STUDY 01

영상 속 지형 함수, 단계별로 보기

같은 시드와 좌표에서 평지·언덕·절벽이 어떻게 달라지는지 비교합니다.
영상 나레이션의 수식과 설명을 재구성한 실험입니다. 화면 코드 전체를 그대로 옮긴 것은 아닙니다.

독립 실험 · 게임 저장 접근 없음






블록 지형 조망
4칸 간격으로 표본을 뽑은 조망입니다. 높이는 1칸 단위이며, 아래쪽 y < 50은 표시를 생략합니다. 노란 선은 선택한 단면입니다.


위에서 본 높이
낮은 돌높은 돌물
지도에 마우스를 올리면 좌표와 높이를 확인할 수 있습니다.
옆에서 본 블록 단면
가로 x = −128…127 / 세로 y = 50…160 · 돌 우선, 남은 곳은 y < 102에서 물




자막에서 확인된 내용
  • y < 100 → 돌, 나머지 공기
  • h = 100 + 20 × Perlin2D(x,z)
  • 높이 아래는 돌, 나머지 y < 102는 물
  • 4회 샘플: 주파수 두 배, 진폭 절반
  • 절벽 점: (−1,50), (0.3,100), (0.4,150), 이후 150
이번 구현의 가정과 한계
  • 시드 셔플 기반 2D Perlin과 기본 좌표 배율 0.01은 보완 구현입니다.
  • 4옥타브는 정규화 없이 더합니다. 이론 높이 범위는 62.5…137.5입니다.
  • 절벽은 단일 Perlin에 점 사이 선형 보간을 적용합니다. 실제 스플라인 방식은 미확인입니다.
  • 3D 밀도·높이 편향의 전체 수식과 동굴 코드는 자막에 없어 미구현입니다.
  • 단위는 실험용 블록 좌표입니다. 게임의 0.5m 셀이나 기존 지형에 연결하지 않았습니다.
