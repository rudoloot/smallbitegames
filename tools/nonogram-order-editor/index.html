노노그램 문제 배치 편집기

실제 도안과 예상 난이도를 보고 순서를 정하세요. 편집 → 브라우저 저장 / JSON 내보내기 → 게임 사본 적용은 별도 단계입니다.

기존 수동 저장 배치는 자동 교체되지 않습니다. 새 기본 배치와 내 저장 배치를 비교해 명시적으로 선택한 후 저장하세요. 표시 번호는 바뀌어도 문제 ID와 기존 완료 기록 연결은 유지됩니다. 난이도는 사람 실측값이 아닌 휴리스틱입니다.

필터 중 이동·정렬은 보이는 항목이 차지한 자리끼리만 바꿉니다. 숨겨진 항목은 같은 자리를 유지합니다. 위치 입력은 ‘필터 결과 안의 순번’입니다. 모바일에서는 ↑↓와 위치 입력을 사용하세요. 키보드는 카드 선택 후 Alt+↑/↓로 이동합니다.

저장과 실제 게임 적용

‘순서 저장’은 이 브라우저의 편집기 전용 저장소에만 기록합니다. 다른 기기에서는 JSON을 내보내 가져오세요. 불러오기·복원 뒤에도 저장 버튼을 눌러야 다음 방문에 유지됩니다.

게임에 반영하려면 내보낸 JSON으로 제공된 order-cli.cjs preview를 확인하고 build-copy로 별도 게임 사본을 만드세요. 현재 실행 중인 게임과 공개 사이트는 자동 변경되지 않습니다. 자세한 명령은 도구의 README.md를 참고하세요.

도안·ID가 다른 팩의 순서 파일, 중복·누락 ID는 불러오지 않습니다. 브라우저 저장을 사용할 수 없는 환경에서는 JSON 내보내기를 이용하세요.
